# Third-party notices

XrayProbe does not bundle Xray-core. It downloads an official Xray-core release from `XTLS/Xray-core` at runtime and executes it as a separate process. Xray-core is licensed separately under the Mozilla Public License 2.0; see the upstream repository and the downloaded release archive for its complete notices.

The default optional metadata endpoint is provided by ipwho.is. The default health and opt-in speed endpoints are provided by Cloudflare. Users can override these endpoints with CLI flags.
